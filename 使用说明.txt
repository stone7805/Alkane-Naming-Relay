烷烃命名接接乐 V1.5 · GitHub Pages 使用说明

1. 解压 ZIP，将其中的 index.html 上传至 GitHub 仓库根目录（覆盖旧版 index.html）。
2. 在仓库 Settings → Pages 中选择 Deploy from a branch，分支 main，目录 /(root)。
3. 访问该仓库的 GitHub Pages 地址；如已有二维码且地址不变，可继续使用原二维码。
4. 手机、电脑都可以玩；页面可离线打开，无外部运行资源。

本次更新：中间下落名称卡缩窄、缩矮，四项间距加大；答对后每轮有不同的夸赞文字和语音，前三轮 60 分有额外庆祝。10 轮、随机题序、可调下落速度、双人独立计分、答错暂停一轮和答对自动续题继续保留。
